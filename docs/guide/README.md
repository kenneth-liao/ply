# Ply user guide

Task-oriented pages for users and agents operating the composer surface.
The README owns the command surface; these pages own the cross-cutting
details a caller needs before acting.

- [Limits and render quality](limits.md) — the one home for every size,
  quality, and refusal limit: canvas size vs supersample factor, outline
  bounds and cost, `measure` tolerances, font weight/width switches, and
  exit codes.
